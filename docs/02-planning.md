# 02 — Calendrier de la semaine : 23 au 27 novembre 2026

Le [**parcours opérationnel complet, avec les jalons, les feux vert/orange/rouge et le travail à la maison**](25-parcours-et-jalons.md) fait désormais foi.

| Jour | Objectif du jour | Vérification en fin de journée |
|---|---|---|
| **Lundi 23** | choisir, concevoir, maqueter, démarrer | maquette, modèle, dépôt, page reliée à la BDD |
| **Mardi 24** | authentification, rôles, socle métier | parcours complet depuis le navigateur |
| **Mercredi 25** | 3 règles, API JSON, évolution | 3 refus/succès explicables + API + analyse d'impact |
| **Jeudi 26** | implémenter l'évolution et corriger un incident | test de non-régression, trace de correction |
| **Vendredi 27** | recette, sécurité, sauvegarde et livraison | application stable, release et démonstration |

**Organisation :** chaque matin un objectif démontrable ; chaque soir un mini point d'étape. Ne commencez pas des bonus lorsque le chemin critique est cassé.

## Priorités en cas de retard

1. Serveur et base.
2. Authentification et droits.
3. Un parcours métier complet.
4. Trois règles contractuelles.
5. API minimale.
6. Évolution et incident.
7. Tests, sauvegarde, documentation et livraison.

**Aucune extension ne doit déstabiliser le socle.** Pour les exemples et critères concrets par sujet, consultez directement sa fiche.
