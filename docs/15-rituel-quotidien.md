# 15 — Rituel quotidien

Chaque jour commence et se termine par un point personnel de quelques minutes.

## Début de journée

Dans `docs/journal.md`, notez :

```text
Date :
Objectif principal :
3 tâches prioritaires :
Risque principal :
Question éventuelle :
```

## Fin de journée

Ajoutez :

```text
Réalisé :
Non terminé :
Problème rencontré :
Décision importante :
Tests effectués :
Premier objectif de demain :
```

## Pourquoi ?

Ce journal :
- vous aide à piloter une semaine courte ;
- facilite le diagnostic si vous prenez du retard ;
- fournit des traces pour expliquer votre démarche ;
- empêche le « j’ai travaillé toute la journée mais je ne sais plus sur quoi ».

Il ne doit pas devenir un roman : quelques lignes honnêtes suffisent.
