## Comment utiliser ces ressources

Ne lisez pas tout d'un bloc.

1. identifiez précisément votre question ;
2. commencez par la documentation officielle ;
3. testez un exemple minimal ;
4. adaptez-le à votre besoin ;
5. documentez ce que vous avez décidé.

Évitez de copier un snippet trouvé sur un forum sans connaître :
- sa version ;
- son contexte ;
- ses implications de sécurité.
