# 16 — Guide d’autonomie

Avant de demander « je fais quoi maintenant ? », utilisez cette procédure.

## 1. Regardez le planning
Votre prochain jalon est-il atteint ?

## 2. Regardez votre backlog
Prenez la tâche `must-have` non terminée la plus importante.

## 3. Si vous êtes bloqué techniquement
Procédez dans cet ordre :
1. reproduire précisément ;
2. lire le message d’erreur ;
3. consulter les logs ;
4. réduire le problème ;
5. vérifier la documentation de l’outil ;
6. tester une hypothèse ;
7. demander de l’aide avec des informations précises.

## Une bonne demande d’aide

```text
Je cherche à :
J’obtiens :
Je devrais obtenir :
J’ai testé :
Le message d’erreur est :
Le code concerné est :
```

## Si vous êtes en avance

Dans cet ordre :
1. terminer les trois règles contractuelles ;
2. renforcer les tests ;
3. réaliser les extensions ;
4. améliorer sécurité et UX ;
5. prendre un bonus.

Ne commencez pas un bonus si une fonctionnalité contractuelle est instable.

## Si vous êtes en retard

Priorité :
1. application lançable ;
2. authentification ;
3. données ;
4. workflow principal ;
5. trois règles contractuelles ;
6. tests essentiels ;
7. évolution/incident ;
8. déploiement/documentation.

Supprimez les bonus et réduisez l’esthétique avant de sacrifier la cohérence métier.
